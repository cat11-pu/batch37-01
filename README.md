# GSB Bugfix Task
## 题面
世界事件刚开到第二阶段，论坛就炸了：全服进度明明已经打满，阶段标题还停在一；任务可以跳过前置直接交；同一条任务重复交三次，代币照给；阶段奖励在阶段没完成时就能领；有人换小号重复领同一阶段奖励；进度条超额的部分被吞掉，下一阶段从零开始。world_event_chain.py 里的 WorldEventChain 负责把阶段推进、任务链和个人奖励连起来。玩家先登记参加，重名和空名拒绝。任务按列表顺序构成一条链，每个人必须按顺序完成；任务所属阶段尚未解锁、任务不存在、本人已经交过，都要拒绝。每交一条任务就给个人代币，并把任务进度累加到全服进度；全服进度达到当前阶段目标后阶段前进，超出部分带入下一阶段继续累计，直到所有阶段走完。阶段奖励按阶段下标领取，只能领已经完成的阶段，每个阶段每人一次；越界下标、未完成阶段和不存在的玩家都要拒绝，领取后返回代币数并记录到领取清单。全服共享同一份阶段进度，但任务完成记录、领奖记录和代币都按玩家独立，完成记录按提交顺序保存，领奖记录按下标升序保存。阶段全部完成后不再推进，多出来的进度仍保留在进度条里。快照要同时看到当前阶段、剩余进度和每个玩家的完成、领取明细，修改快照不影响内部状态；任务提交失败不会写入完成记录，也不会占用该任务的领取资格；阶段下标从零开始，重复领取同一阶段按失败处理；全服进度按任务实际贡献累加，溢出部分只在阶段切换时结转一次。

## 运行方式
```bash
python -m pytest tests -q
```
