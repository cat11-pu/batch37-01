# GSB Bugfix Task
## 题面
赛事复盘工具上线后，解说和教练一起投诉：拖到第 37 秒，画面却从第 20 秒的关键帧重新算，界面显示的重放开销和实际差一截；时间轴拖过片尾还能继续走，时间显示成 137 秒，导出直接失败；收藏点在列表里按创建顺序排，不是按时间排；两个解说给同一秒起相同的收藏编号，后一个把前一个顶掉；每人的收藏数量没有上限，面板滚不到底；删除收藏不分创建者，运营一动手就把选手的标记删了，第二个人再删还收到成功提示；热力图只能看单场，跨场对比要人工相加，时间窗过滤也不生效；事件没有坐标时热力图把它算进原点，数据全歪。replay_analytics.py 的 ReplayAnalytics 要实现 seek、bookmark、bookmarks、remove_bookmark、heatmap 和 state。seek 找到不晚于目标时间的最近关键帧，返回帧时间、重放开销和是否被片长截断，重放开销是从该帧重放到目标时间的差值，负数时间拒绝；收藏编号全局唯一，时间必须落在片长内，备注不能为空，每人每场有数量上限，删除只允许创建者；热力图按格子边长把坐标降维计数，键写成 x,y 两个格子下标，支持左闭右开的时间窗，不传场次时汇总所有场次，没有坐标的事件跳过；格子非法、窗口倒置、场次不存在按参数错误处理；按时间轴拖动时界面要显示当前关键帧编号和到下一帧的剩余时间；热力图统计事件次数而不是去重玩家数，同一格子多次事件要累加；收藏达到上限时新增要明确报错，不能静默丢弃；关键帧数组按升序给出，查找时不能依赖数组下标；state 里的收藏按场次分组，返回完整副本。
