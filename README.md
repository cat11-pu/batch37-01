# GSB Bugfix Task
## 题面
公会战扩成多节点争夺后，锁定期和计分规则开始互相打架：刚被占下的节点对手立刻能反打，锁形同虚设；自家公会能攻击自己占据的节点；攻击力低于防御值也判定占领成功；节点易主后原公会分数没有扣减，结算之后还能继续开战，从状态里拿到的归属快照被改动后影响后续判定。锁只对非占领方生效，节点被新公会占领后锁的到期时间从头计算；分数查询对未参战公会返回零，结算后仍可读取最终分数；状态快照要带上节点归属、锁到期时间、各公会分数和结算标记。guild_war.py 的 GuildWar 负责 attack、score、settle 和 state。实现要记录每个节点的归属、防御值和锁到期时间，占领成功后为胜方加锁并拒绝其他公会，锁到期允许再次进攻，攻击力必须达到防御值，不能进攻己方节点，分数只累加当前占领节点的价值，结算冻结战局，第二次结算会被拒绝；未知节点、攻击力不是正整数或者节点编号为空都直接报 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
