# GSB Bugfix Task
## 题面
宠物对战上线后数值策划被玩家追着问：速度一样的两只宠物，出手顺序每次都不一样；防御堆到四十还是被一击打掉半管血；冷却两回合的大招隔一回合就能再放；轮到对方行动时自己还能插队；宠物倒下后战斗没有结束，双方继续互相扣血；同一只宠物能同时进两场战斗；战斗打到一半血量显示成负数。pet_battle.py 里的 PetBattle 要把宠物属性、回合制出手和技能冷却拼成完整的战斗循环。每只宠物有血量、攻击、防御和速度，开局双方满血；速度高的先手，速度相同按名字升序，双方每一轮各行动一次，出手顺序开战时就确定。出手必须轮到自己，技能必须存在且不在冷却中，否则拒绝且不消耗回合。伤害按攻击加技能威力再减对方防御计算，最低为一点；血量降到零立即结束，胜者确定，之后任何操作都拒绝。冷却按自己的回合计数：冷却为二的技能用完之后，接下来两个自己的回合都不能再用，冷却查询返回还剩几个回合不能用。同一只宠物不能同时参加两场没有结束的战斗。快照要包含双方血量、当前回合、行动方、状态和每个技能的剩余冷却，修改快照不影响真实战斗；技能冷却按宠物单独记录，同一技能在不同宠物之间互不影响；战斗结束后双方血量定格，不能通过再次出手改写结果；开战前校验宠物配置，血量、攻击、防御、速度必须是非负整数；同一轮内先手方倒下时，后手方不再获得行动机会；查询不存在的战斗编号一律报错；伤害结果不做随机浮动，保证同配置可以复现。

## 运行方式
```bash
python -m pytest tests -q
```
