# GSB Bugfix Task
## 题面
副本里的战斗音频混音翻车了：Boss 语音一响，背景音乐还压在原音量上，解说完全听不清；玩家躲到墙后，脚步声明明该发闷，结果和贴脸一样响；同一条总线上的音效没有数量上限，团战时几十个声音一起播，帧率掉到个位数；优先级低的音效把语音挤掉，结束后也不恢复；总线静音只静自己，子总线照常出声；父总线音量调小，子总线一点不受影响；停掉音效以后，混音表里还留着它的增益；听者走动以后，远处的声音还是按出生点算距离；语音结束后音乐要等下一次场景切换才回到原音量。audio_scene.py 的 AudioScene 要实现 play、stop、update、set_bus、mix 和 state。总线按父子关系连乘音量，静音会清零整棵子树；play 记录音效编号、总线、坐标、响度与优先级，坐标为 None 表示界面音，不做距离衰减；音效按到听者的直线距离衰减，公式是 1 除以 1 加距离，中间隔着墙段时再乘遮挡系数，遮挡只看听者到音效这一段线段与墙段是否相交，听者移动后重新计算；每条总线有通道数限制，满了就挤掉优先级最低的一个，新音效优先级不高于最低者时报错；语音总线有活动音效时目标总线按配置分贝下压，语音停止后恢复；增益保留四位小数；未知总线、重复音效编号和非法坐标都要拒绝；通道数只统计当前总线自己的音效，不把子总线的算进来；音效停止后从活动列表移除，不再参与优先级比较；遮挡系数和距离衰减各作用一次，不能重复相乘；总线音量改变后所有活动音效立即按新增益计算；mix 的 active 里每个音效给出 gain、bus、priority，state 返回总线、音效和听者信息的副本。

## 运行方式
```bash
python -m pytest tests -q
```
