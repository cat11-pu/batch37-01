# GSB Bugfix Task
## 题面
肉鸽跑图的存档在测试里反复丢进度。每层房间是随机生成的，但同一个种子每次进游戏布局都不一样，Boss 有时出现在中间，商店和休息房可能整层都没有；房间只能按顺序进，跳着进不报错，没清完前面的房间也能直接打 Boss。遗物叠加只记录了名字，火焰遗物拿三层和拿一层打出来伤害一样，超过上限还能继续捡。战斗结算没有先手概念，敌人血量取整算错，英雄残血时会打出负数伤害；休息房回血不封顶，精英房的遗物掉落没有提示。roguelike_run.py 里的 RoguelikeRun 要把按种子生成房间、顺序进入、战斗、商店、休息、精英、Boss 结算、遗物叠层、楼层推进和存档恢复做完整。每层固定五间房，前四间是战斗、精英、商店、休息各一间并按种子洗牌，Boss 永远在最后；同种子同层布局必须一致。只能进入当前待进入的那一间，没进房不能结算，结算后房间标记已清并推进到下一间。战斗按英雄攻击先手，普通敌人血量为基础值加楼层乘二，精英再加四，Boss 翻倍，敌人血量除以攻击向上取整得到回合数，英雄承受回合数减一乘敌人攻击的伤害；精英通关提示掉落 ember，商店按标价购买遗物，休息回血但不超过上限。火焰遗物每层加二攻击，最多叠三层，未知遗物和超上限都拒绝。Boss 清完后进入下一层并重新生成房间，最后一层通关标记胜利。存档要能原样读回楼层、血量、金币、遗物、待进入编号和房间列表，血量越界或结构被改的存档直接拒绝。待进入编号越界、结算已经清过的房间、商店金币不足都要报错；每层敌人强度按楼层递增，精英和 Boss 血量更高，遗物加成只影响英雄攻击，不改敌人血量。

## 运行方式
```bash
python -m pytest tests -q
```
