# GSB Bugfix Task
## 题面
野外任务和刷怪预算连在一起后，新手村生态彻底乱了：任务要三只野狼，刷怪点一次只出一只，玩家排长队等刷新，刷新计时器按真实时间走，服务器重启后又从头开始；预算早就花光，系统还在刷精英，怪堆到存活上限也不停；两个刷怪编号撞在一起，两只怪共用一条血量，打死一只另一只跟着消失；任务计数把附近所有死亡都算进去，打蝙蝠也推进杀狼进度；任务没接也能涨进度，放弃以后进度还留着；掉落的材料凭空消失，玩家背包一直是空的；进度没满就能交任务，奖励照发；同一个任务还能接两次；玩家在别的区域杀同名怪，任务也照样计数；同时开两个副本，预算互相不隔离，一个副本把另一个的怪刷光。spawn_quest.py 的 SpawnQuest 要实现 spawn、kill、despawn、accept、abandon、turn_in、objectives 和 state。每个区域有预算和存活上限，刷怪按怪物点数扣预算，超过预算或上限拒绝；spawn 记录刷怪编号、区域、怪物、点数和时间，击杀或清场后编号可以再次使用；击杀和主动清场都归还预算，只有击杀结算掉落和任务进度；进度只统计已接任务、区域和怪物都匹配的击杀；数量达标才能交付并发放金币，未达标、重复接取、未接就放弃、未知任务或怪物都要报错；objectives 按任务编号排序列出进行中和已完成的任务，带 quest_id、target、progress、required、status；任务进度达到上限后不再增加，多余的击杀不浪费掉落；清理不存在的刷怪编号要报错，不能静默忽略；区域预算和存活上限分开判断，先看编号是否重复；每次清理都要同步更新预算和存活数量；state 给出区域占用 used、存活列表和每名玩家的任务进度。

## 运行方式
```bash
python -m pytest tests -q
```
