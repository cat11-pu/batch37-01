# GSB Bugfix Task
## 题面
游戏内交易所改成撮合制以后，玩家投诉成交价乱跳：同样价位的买单，后挂的单先成交；高价买单明明排在前面，却被低价单抢走；大单只成交了一部分，剩余数量直接从挂单簿里消失；成交价有时按新来的单算，有时按先挂的单算，对账时怎么也对不上；重复的单号还能覆盖旧单，撤单接口连不存在的单也返回成功。economy_market.py 的 OrderBook 要实现 submit、match、cancel、book、trades 和 state。submit 接受唯一的订单号、buy 或 sell 方向、正整数价格与数量、非负整数时间；match 按价格优先、同价时间优先撮合，最高买价不低于最低卖价才成交，成交价取先挂出的那一单的价格，支持部分成交并保留剩余数量，返回本次新增的成交列表；match 可以连续调用多次，已经成交的历史不会在后续调用里重复返回；cancel 只能撤销仍在簿上的订单，撤不存在的单号要报错；部分成交的订单继续留在簿上，剩余数量仍按原先的价格与时间优先级排队；book 分别给出买卖两侧按优先级排列的剩余量；trades 与 state 返回历史快照，外部改动不影响内部数据。

## 运行方式
```bash
python -m pytest tests -q
```
