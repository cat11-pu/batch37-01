# GSB Bugfix Task
## 题面
世界 Boss 改成分阶段战斗后，伤害账和奖励账对不上：血量跌破阈值还按第一阶段倍率结算，溢出伤害被算进个人贡献，Boss 倒下后仍可继续攻击，结算之前就能查询奖励，同一场战斗结算两次会重复发奖，没出过手的角色也出现在奖励表里。同一玩家多次出手的贡献要累加，不同玩家分开统计；阶段只前进不后退，血量比例刚好落在阈值时按新阶段处理；奖池除不尽时剩余部分留在池中，没有贡献记录的角色查询奖励要直接报错；结算结果保留下来供 reward 查询，state 快照包含血量、阶段、存活标记、贡献和结算状态。world_boss.py 的 WorldBoss 实现 attack、settle、reward 和 state。规则是阶段随剩余血量比例切换，倍率按出手时的阶段生效，单次有效伤害不超过剩余血量，贡献只累计实际扣血，血量归零后拒绝攻击，settle 按贡献占比向下取整分配奖池且只能执行一次，reward 只对已结算的参与者返回金额；非正整数伤害、非法阶段配置和重复结算抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
