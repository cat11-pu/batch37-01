# GSB Bugfix Task
## 题面
地形导出的三角面数一直压不下来，一个方块区域的六个面全被拆成独立四边形，贴着的内侧面也没剔掉，显存和提交批次都吃紧。voxel_mesher.py 里的 VoxelMesher 接收 {(x,y,z): 方块编号} 的字典，build 要返回 quads、vertices、indices 和 stats 四部分：同一朝向上材质相同且相邻的面合并成尽量大的矩形，实心块彼此接触的内侧六面直接剔除，编号为零视作空气。合并结果还要稳定：字典插入顺序打乱、连续调用两次，顶点坐标、索引和面片顺序都必须完全一致，顶点绕序的法线与面朝向对得上。比如两个并排的同种方块，上下前后四个方向应该各留一个长条，而不是八个碎面。stats 给出合并后的四边形数、剔除后剩余的面数、顶点数（每面四个）和索引数（每面六个）。空网格不能报错，坐标允许负数，零编号块不产生任何面。

## 运行方式
```bash
python -m pytest tests -q
```
