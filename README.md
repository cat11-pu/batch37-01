# GSB Bugfix Task
## 题面
背包从固定格改自由网格后，整理装备时不断丢东西：两件占用区域重叠的武器能同时放下，长枪旋转后仍按原尺寸占格，越界坐标被自动折回边界，叠加超过上限的部分直接消失，取出部分数量后整个格子仍被占着，移动到新位置时穿过其他物品。网格坐标以左上角为原点，宽高按整数格计算，物品占格信息要随状态一起返回；同一物品再次堆放只改数量、不新增占用，取出后剩余数量继续留在原位；可用空间不足时移动必须整体失败，不能把物品挤到别的格子。inventory_grid.py 里的 GridInventory 要实现 place、stack、remove、move、can_place 和 state。实现要求放置矩形完全落在网格内且彼此不重叠，rotated 为真时宽高互换，同一物品的叠加默认上限为 5 且失败时数量保持不变，取出默认减少 1 个、减到零才释放占用，移动先校验再更新位置，can_place 只返回可行性并且不改动状态；重复物品、负数坐标、超量取出和非法尺寸抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
