# GSB Bugfix Task
## 题面
射击服务器接弹道回查后，命中判定开始漂：瞬发武器按开火瞬间站位算，移动目标明明已经走开还算中；飞得慢的弹丸没有算飞行时间，命中时刻和服务器记录的时刻对不上；目标中途躲到掩体后仍被算中；旧帧被裁剪后回查直接报错；同一时刻重复上报覆盖上一份位置。hit_rewind.py 的 HitRewind 负责 record 和 register。实现要按弹速和距离推命中时刻、取那一刻的目标坐标算距离、命中时刻有掩体就判 miss、只允许命中时刻之前最近的一份记录、半径边界和参数校验、历史裁剪与拷贝隔离；非法输入抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
