# GSB Bugfix Task
## 题面
公会副本改成周锁定之后，会长快被邮件淹了：有人退会后还能继续打 boss；同一个人一周内在同一 boss 上反复拿奖励；伤害统计只记最后一刀，输出第一的坦克分不到金币；团长被误删以后公会直接没了；打完一条龙去摸另一条龙，系统却说本周已经锁定。guild_raid.py 里的 GuildRaid 要把成员名册、boss 周锁定、伤害累计和奖励分配四件事绑在一起。添加成员时记录等级和职位，重名、空名、非正等级、第二个团长都要拒绝，团长本身也不能被移除；职位只接受团长、干部和普通成员三种。只有名册内的成员能出手，伤害必须是正整数，boss 倒下后拒绝继续攻击；攻击不存在的 boss 或对本 boss 尚未解锁的玩家出手，同样拒绝。每次攻击按实际扣掉的血量记到个人头上，溢出部分不计入个人贡献，并返回 boss 剩余血量；击破时按伤害占比分配奖池，先算每人的整数份额，除不尽的余数给伤害最高的人，并列时名字排序靠前者优先。参战成员获得该 boss 的本周锁定，锁定按 boss 分开计算，不跨 boss 生效；没打出伤害的成员不能领奖，同一份奖励只能领一次，领取后从待领表移除。每周重置把血量、伤害、锁定和待领奖励全部清空，成员名册保留，重置后原先被锁的人可以重新开打。所有校验失败都不能改动任何状态，快照里能查到名册、各 boss 血量与状态、本周伤害、锁定名单和奖励表；锁定名单按 boss 分别记录，退会成员的伤害记录保留到本周重置，方便复盘；重置操作可以重复执行，结果保持一致；每次变更都同步写入快照，方便会长自查。

## 运行方式
```bash
python -m pytest tests -q
```
