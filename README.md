# GSB Bugfix Task
## 题面
客服工单接入日志检索后，用户隐私开始从自由文本里漏出来：邮箱、手机号、身份证号和 IPv4 混在备注里没有被替换；嵌套字典和列表只处理了第一层；同一条信息在多个字段重复出现时掩码不一致；版本号 1.2.3.4 被误判成 IP；已经脱敏的字段再次处理变成了双重掩码。pii_redactor.py 的 PiiRedactor 负责 redact。实现要递归处理字典、列表和字符串，按邮箱、手机号、身份证号、IPv4 规则替换成固定占位符，保留版本号等普通数字，重复处理保持幂等，输入结构不被修改。

## 运行方式
```bash
python -m pytest tests -q
```
