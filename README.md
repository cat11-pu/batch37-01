# GSB Bugfix Task
## 题面
文件服务一开放下载，路径穿越就来了：../ 能跳出根目录，%2e%2e%2f 解码后也能跳，反斜杠和空字节能绕过检查，软链接指到根目录外照样读。path_jail.py 的 PathJail 要实现 resolve。要先把百分号编码解开再规范化、拒绝绝对路径和任何越界、处理反斜杠和 NUL、默认不跟随指向根目录外的软链接；根目录、相对路径和软链接策略都要校验。

## 运行方式
```bash
python -m pytest tests -q
```
