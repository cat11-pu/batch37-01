# GSB Bugfix Task
## 题面
关卡里的洞穴环境音接上卷积混响后，导出音频总是比原声短一截，脉冲响应最后那段尾音被整个吞掉；把内部块大小从 64 改成 256，同一段素材的波形立刻对不上，说明分块逻辑本身有错；湿声比例调到 0.3 以后干声也跟着变小，两组系数被绑在了一起；分块推流时块与块的交界处出现规律的咔哒声，上一块算出的拖尾没有带进下一块；调用重置之后旧尾音还会从缓冲区漏出来。audio_reverb_fft.py 里的 BlockReverb 要实现构造函数以及 process、push、flush、reset、state：脉冲响应不能为空，块大小必须是正整数，wet 与 dry 各自限制在 0 到 1；process 用块卷积算出完整线性卷积，输出长度等于输入样本数加脉冲长度减一；push 每次返回与本次输入等长的一段，跨块保留历史样本，flush 交出剩余尾音，推流结果与 flush 拼接后必须和 process 完全一致；脉冲长度为一的时候没有尾音，flush 必须返回空列表，空输入调用 process 也返回空列表；state 给出脉冲、块大小、混合系数和已处理样本数，任何外部改动都不能影响内部状态。

## 运行方式
```bash
python -m pytest tests -q
```
