# GSB Bugfix Task
## 题面
合服之后角色可以付费转服，晚高峰一到队列就出问题：目标服明明满员，申请还是能提交，提交后角色卡在两个服之间；同一角色十分钟内连转三次，冷却时间形同虚设；背包里的绑定传家宝跟着角色被带走，破坏了另一边的经济；超重背包不拦截，落地后物品溢出丢失；玩家取消申请后冷却反而被占用；两个人抢最后一个名额都能提交成功，先提交的反而失败。server_transfer.py 的 ServerTransfer 负责 request、commit、cancel 和 state。申请阶段校验服务器、角色归属、冷却与背包重量，提交时重新确认目标服容量，成功后才写入冷却并整体搬迁背包；取消不消耗冷却，已取消的申请不能再提交；服务器不存在、角色不在原服、背包超重或含绑定物品均抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
