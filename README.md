# GSB Bugfix Task
## 题面
好友送礼改走邮件以后，客服后台被工单淹没：不是好友也能送礼，陌生人往背包里塞了一堆垃圾；寄件人的物品已经扣掉，收件人离线却什么都没收到；同一对好友反复点赠送，一天送出去十几份；邮件过期还能领取，重复点击还能再领一次；对方把自己删掉后，邮件里的礼物跟着蒸发；每日限额按收件人计算，换个人又能继续送；收件人邮箱里的同名邮件互相覆盖；礼物退回来时物品凭空消失，寄件人拿不到；邮件附件在服务器重启后丢失，寄件人自己离线时赠送也失败。social_gift.py 中 SocialGift 负责好友、赠送与邮箱，入口是 request_friend、accept_friend、unfriend、friends、send_gift、claim、expire、state、inbox。好友关系先申请再确认，申请记录申请人与接收人，只有接收人同意才生效，两边列表一致，重复申请和确认不存在的申请都要拒绝；删除好友后双方列表同时清掉，重复删除报错；只有好友之间能送礼，物品数量必须为正且不能超过寄件人库存，礼物编号不能重复，记录寄件人、收件人、物品和发送时间；收件人在线时礼物直接进背包，离线时进邮箱，过期时间从发送时刻开始算；领取只能由收件人操作且只能一次，过期邮件在 expire 之后不能领取；每个寄件人每天有送礼次数上限，按自然日重置，失败的那次不占额度；申请列表里同一个人只能有一条待确认记录，过期申请要清理；礼物物品数量按整数校验，零和负数直接拒绝；邮箱按到达时间排序，领取时带上邮件编号；申请和领取都要校验双方玩家是否存在；state 包含在线状态、物品、好友、邮箱和每日已用次数。

## 运行方式
```bash
python -m pytest tests -q
```
