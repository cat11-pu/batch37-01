# GSB Bugfix Task
## 题面
签到连续天数算得乱七八糟：跨时区的人同一天能签两次；隔天忘签一次就直接清零；宽限天数配了却没效果；最高纪录跟着一起丢；改过时区之后同一个瞬间还能再签一遍。daily_streak.py 里的 DailyStreak 要补齐本地日期换算、签到、查连续数、查最高纪录、改时区偏移和取快照：时区用分钟偏移表示，本地日期按偏移把时间戳换算成日期序号；同一天重复签到拒绝；间隔一天累加；开了宽限允许多跳几天，超过宽限就从头算；签到结果同时给出连续数、日期和累计次数；时间戳必须是非负整数，偏移只接受 -720 到 840，宽限不能为负，查不存在的玩家要报 ValueError。累计次数只统计真正签到的天数，空档和补签都不加；断签之后最高纪录仍保留历史最大值；本地日期序号从时间零点起算。签到失败要原样报错，不能顺手把连续数改掉；同一天多次调用只保留第一次的结果。快照跟内部隔离。

## 运行方式
```bash
python -m pytest tests -q
```
