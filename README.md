# GSB Bugfix Task
## 题面
演唱会场景的观众群模拟一开就卡：每帧对所有人两两算距离，两千人就掉到十几帧；只隔一条网格边界的两个人明明在感知半径内却被漏掉；把网格尺寸调大调小，邻居集合跟着变，行为完全不可复现；三个人挤在同一点时分离力算出无穷大，整群直接飞走；合力没有上限，个别人一帧被弹到地图外；速度也没有封顶，跑得快的个体永远追不上。crowd_steering.py 要提供 neighbor_grid、boids_forces 和 step。neighbor_grid 用均匀网格分桶，返回每个个体在半径内的邻居下标并按升序排列，距离正好等于半径也算邻居，结果必须与暴力距离判断一致且不受格子尺寸影响，格子尺寸默认取感知半径；boids_forces 按分离、对齐、聚合三个权重求合力，重合个体的分离项记为零，最终向量长度不超过 max_force；step 先按合力更新速度并把速度限制在 max_speed，再用新速度推进位置，返回新的位置与速度列表而不改动传入的列表；位置与速度数量不一致、半径或时间步非正时抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
