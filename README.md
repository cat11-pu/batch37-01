# GSB Bugfix Task
## 题面
《远征》国际服开放钻石与金币互兑后，运营发现账目越来越乱：玩家对同一张兑换单连点几次，每次都会扣款；汇率更新后旧价格仍然生效，按几分钟前的行情成交；用金币反兑钻石时直接报找不到汇率；单笔金额没有上下限，有人拿 1 金币刷了几千次接口；每日额度跨零点不重置；手续费从本金里扣，到账数字和报价对不上。currency_exchange.py 的 CurrencyExchange 负责 set_rate、quote、convert、used_today 和 state。正反向汇率都要能查且超时作废，单笔额度与每日额度分别校验，同一请求号重复提交只生效一次，余额和额度都只扣一次，报价与到账金额保留两位小数；币种相同、汇率非正、金额越界或余额不足都抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
