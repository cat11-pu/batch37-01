# GSB Bugfix Task
## 题面
战斗回放拖动进度条时特别卡，每一帧都从头重算，拖回前面又得重新模拟；缓存没有命中统计，开发也说不清重建了几次。replay_seek.py 的 ReplayBuffer 用关键帧加增量保存状态：构造参数是关键帧间隔，append(state) 接收实体到字段的字典并返回帧号，每隔固定帧数存一份完整快照，其余帧只记录相对上一帧新增或改写的顶层键和删除的键；seek(index) 从不超过目标帧的最近关键帧出发依次应用增量，返回深拷贝，越界或负数抛 IndexError。cache_info 返回 hits、misses、size，同一个帧第二次读取要命中缓存；stats 返回帧数、关键帧下标列表和缓存条目。重建必须确定：先跳后跳、来回拖动、另建一个实例直接跳到同一帧，结果都要一致。间隔小于一、追加的不是字典都抛 ValueError，空缓冲读取也不能悄悄返回空字典。

## 运行方式
```bash
python -m pytest tests -q
```
