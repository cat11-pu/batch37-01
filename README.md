# GSB Bugfix Task
## 题面
观战镜头在回放里表现得很怪：角色贴墙时镜头直接穿进墙体，能看到地图外面；镜头离角色太近时整个人被模型挡住，画面只剩一片黑；障碍明明在镜头背后，镜头还是往角色身上缩；镜头卡在墙角时每隔一帧就在两个位置之间跳；拖动回放时间轴，镜头从上一个机位慢慢飘过去，画面糊成一片；松手继续播放又猛地跳一下；轨迹只记录最终位置，倒回去找不到当时的机位；平滑参数设成 1 和 0 表现一样，不是瞬移就是完全不动；导播切换选手时镜头从上一位的位置滑过来，中间穿过整张地图；两次回放同一段轨迹，落点每次都不一样。camera_replay.py 的 CameraReplay 要实现 solve、snap、step、timeline、replay_seek 和 state。solve 是纯函数，从角色位置沿指定方向求期望机位，障碍用球心和半径描述，射线只看目标到期望机位这一段，遇到障碍就停在障碍前 padding 处，且不得近于最小距离，零方向或非正距离报错；snap 立即落到解算位置并写入轨迹，step 按平滑系数向解算位置插值，公式是当前位置加差值乘以配置里的 smooth，第一次调用直接对齐；step 与 snap 都把时间和位置写进轨迹；timeline 按时间过滤并保持先后顺序；replay_seek 取不晚于目标时间的最近一条轨迹并立即对齐，不经过平滑，目标早于首条记录时报错，晚于末条时停在末条；轨迹按时间升序保存，同一时间点重复写入以最后一次为准；解算只依赖障碍、方向和距离，不读取上一次机位；平滑系数限制在零到一之间，越界按配置错误处理；期望机位按单位方向乘以距离计算，方向长度不影响结果；state 返回机位当前位置和轨迹的副本。

## 运行方式
```bash
python -m pytest tests -q
```
