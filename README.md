# GSB Bugfix Task
## 题面
装了一堆模组后启动器开始报错：依赖写在 mod.json 里但加载顺序反了，缺依赖时只弹一句红字，版本要求 >=1.2.0 被当成字符串比较，两个互相冲突的模组照样一起进游戏，循环依赖直接把加载器卡死。mod_loader.py 的 ModResolver 要实现 resolve。要按依赖关系排出确定顺序、检查缺失和禁用的依赖、按语义版本判断约束、检测冲突和环、重复 id 和非法版本要拒绝；同级模组按 id 稳定排序。

## 运行方式
```bash
python -m pytest tests -q
```
