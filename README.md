# GSB Bugfix Task
## 题面
新区开放付费邮寄后，客服每天都能收到丢件投诉：寄件人点发送时物品已从背包扣掉，收件人却一直看不到邮件；带价邮件在对方金币不足时仍被领取，余额被扣成负数；同一封邮件连点两次领取，附件复制出两份；超过保管期的邮件既不退件也不消失，一直占着邮箱容量；陌生人拿到邮件编号就能领走别人的附件；退件只还物品，寄件人垫付的费用没有结算。trade_mail.py 的 TradeMail 需要实现 send、claim、expire、inbox 和 state。寄出即托管，仅收件人可领取；货到付款先校验金币再转账给寄件人；重复领取、过期领取一律拒绝；到期由 expire 统一退回附件并记录状态；收件箱只列出仍待领取的邮件；重复编号、负价格、零保管时长用 ValueError 拒绝，越权领取抛 PermissionError。

## 运行方式
```bash
python -m pytest tests -q
```
