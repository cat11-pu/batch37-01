# GSB Bugfix Task
## 题面
排位赛合服之后匹配彻底乱了：分差三百的两个人被塞进同一场；同一个人能同时排两次队；奇数人开赛直接崩；四强赛胜者还没出来，决赛对阵就先显示了；同一场比赛上报两次胜者，奖励发了两份；亚军和四强选手的奖励混在一起；比赛结束后再上报还能改冠军。match_tournament.py 里的 MatchTournament 要把排队撮合、单败淘汰树和名次奖励接起来。入队登记玩家与积分，重名和负积分拒绝；离队只能移除队列中的玩家。撮合按入队先后扫描，给每个人寻找积分差不超过窗口的最早对手，配成一场比赛并移出队列，差值正好等于窗口也算合格，凑不成对的留在队列里，并保持原来的先后顺序。开赛要求队列已经清空、首轮场次数量是 2 的幂，否则拒绝；开赛后生成轮次表，首轮沿用已经生成的比赛编号，每轮场次减半直到只剩一场决赛。上报胜者只能针对尚未上报的比赛，胜者必须是参赛双方之一；一场比赛只能上报一次，未开赛就上报无效。每一轮全部结束后自动生成下一轮对阵，下一轮按上一轮场次的先后拼接；决赛结束确定冠军，冠军、亚军和半决赛负者分别拿对应奖励，其他参赛者为零。奖励在决赛上报时一次性结算，奖励查询对不存在的玩家拒绝，状态快照与内部数据隔离；同一名玩家不能重复出现在轮次表里，晋级后原场次仍然保留供查询；决赛上报后撮合接口关闭，剩余操作只能查询；轮空只允许出现在配置错误的情况，正常开赛不接受轮空。

## 运行方式
```bash
python -m pytest tests -q
```
