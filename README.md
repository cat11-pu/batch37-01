# GSB Bugfix Task
## 题面
帧同步回放一跑长局就漂：同一帧两个玩家的输入按到达顺序结算，换台机器结果就反了；随机数状态没有进入回滚快照，回滚后暴击结果变了；浮点累加在不同平台有微小差异，十秒后位置差出一格；输入队列只存当前帧，迟到输入直接覆盖未来帧；校验和只算位置，冷却和 buff 对不上也发现不了。deterministic_sim.py 的 DeterministicSim 负责 set_input、step、checksum 和 state。实现要按帧和玩家 id 固定排序输入、用定点数累加、把随机数状态纳入快照和校验和、拒绝重复帧输入、迟到输入不能改写已确认帧，状态返回副本。

## 运行方式
```bash
python -m pytest tests -q
```
