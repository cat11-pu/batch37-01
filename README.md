# GSB Bugfix Task
## 题面
开季三天，客服后台被截图刷屏：有玩家经验早就过了第一档，等级栏还挂着零；昨天卖空的限时药剂今天仍在货架上，库存显示成负数；同一档奖励连点两下，金币直接翻倍；没买通行证的小号把付费轨领走了；买东西金币扣了，货架数量却纹丝不动；跨天之后有人看到的还是昨天的商品。season_shop.py 里的 SeasonShop 要把赛季通行证、每日轮换商店和玩家钱包串成一条线。入会登记玩家并发一笔初始金币，重复入会、空名字、负金币一律拒绝。经验按档位阈值折算等级，到最后一档封顶，零或负经验不接受，加经验返回自己最新的等级。货架按轮换表给出当天商品的价格、剩余库存和解锁等级；换日后库存回到配置值，前一天剩下的不会顺延，不在当天表里的商品不能下单；轮换表按天循环，同一天反复查询不能改变库存。购买时等级、库存、余额三项一起校验，全部通过才扣钱扣货，任何一步失败都不能出现扣了钱没出货或出了货没扣钱的状态，成功时返回实付金额。通行证从钱包扣固定费用，重复购买拒绝；免费轨和付费轨的奖励先判断档位是否已达、该轨是否已领，通过后金币入账并返回奖励数额，付费轨还要求已经持有通行证；档位号从 1 开始，超出总档位同样拒绝。玩家不存在时查询余额、下单或领奖都要报错，不能悄悄新建档案。快照要能查到每位玩家的经验、等级、金币、通行证状态和两条轨的已领清单，并与内部账本隔离，外部修改快照不能回写；任何失败操作都必须保持原来的金币、库存和领取记录不变。

## 运行方式
```bash
python -m pytest tests -q
```
