# GSB Bugfix Task
## 题面
好友送礼的每日限额根本挡不住：一次送好几份没累计；跨天不重置；同一个礼包编号当天能重复发；收礼方没回礼也能领；过期礼物照领不误；重复提交还重复记账。friend_gift.py 里的 GiftManager 要补齐加好友、送礼、收礼、待领列表和取快照：好友关系双向，不能加自己或空白名字；送礼按发送方当天累计的礼物份数卡上限，同一天同一礼包编号只算一次，返回记录里带份数、发送时刻和按有效期推出的过期时刻；收礼要求收礼方当天给发送方送过至少一份，过期、已领、找不到都报 ValueError；待领列表只列没领且没过期的编号并按字典序排列。好友关系一方添加双方生效；每日上限按自然日切分，过零点重新计数；领取成功后该礼包立刻从待领列表消失，不能二次入账。送出的份数超过剩余额度时整笔拒绝，不允许先扣一部分；送礼记录按发送顺序留存。快照不得暴露内部列表。

## 运行方式
```bash
python -m pytest tests -q
```
