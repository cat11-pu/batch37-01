# GSB Bugfix Task
## 题面
文件下载服务开放相对路径后，安全审计发现可以跳出根目录：../、%2e%2e%2f、双重编码、反斜杠和 NUL 都能绕过；绝对路径直接读系统文件；软链接指向根目录外仍然放行。path_jail.py 的 PathJail 负责 resolve。实现要先把百分号编码解开再规范化，拒绝绝对路径、越界路径、反斜杠和 NUL，默认不跟随指向根目录外的软链接；根目录必须是绝对路径，空路径和非字符串也要报错。 下载接口会把解析后的路径交给后续的打开和读取步骤，解析结果必须是最终真实路径，不能在检查之后又被软链接替换。

## 运行方式
```bash
python -m pytest tests -q
```
